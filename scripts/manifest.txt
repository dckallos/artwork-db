# scripts/manifest.txt -- ordered forward apply list for the IaC layer.
# One repo-relative path per line; blank lines and #-comments are ignored.
# Read by scripts/orchestrate.sh as the single source of truth for apply order
# AND teardown reversal, replacing sorted(glob(...)). Teardown reverses this
# list and applies only the paired drop of each create_* entry (create_ ->
# drop_); non-create_ entries (e.g. refresh_grants.sql) have no paired drop and
# are skipped. Order follows the 2026-05-29 design decision
# "IaC Phase Ordering + Role Model: Git mirror runs last": core infrastructure
# first, then the optional git-setup Git mirror last.
#
# Decouples apply order from filenames entirely (H2). Filenames no longer carry
# numeric prefixes; this manifest is the sole source of apply order. The only
# behavioral delta from the original prefix-glob is create_grants.sql (formerly
# grant_privileges.sql), which the old V*__create_*.sql glob silently skipped
# and which now applies in place.
